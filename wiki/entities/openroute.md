# Openroute

One of the three [[agent-harness]] dispatch targets for [[capybara]] tasks (per [[requirements-app]]). Confirmed 2026-10-04 by [[wald]]: OpenRouter (openrouter.ai), the LLM API gateway/router.

**Tension (noted 2026-10-04):** [[agent-harness]] pages group the three targets as harnesses, but OpenRouter is an API gateway that routes to models — it hosts no agent loop itself. See the note on [[agent-harness]].
