# ASD-STE100

Simplified Technical English — the specification language for this repository (R1 in [[requirements-repo-rules]]). A controlled-language standard: approved words only, short sentences, active voice, one instruction per sentence, verbs only in approved forms. The [[capybara]] requirement docs in `raw/` are written in this style.

Binding at the schema level since 2026-10-04: the `AGENTS.md` "Specification language" section requires STE for every requirement, rule, and specification document in this repository, including documents the LLM drafts. Wiki summaries and log entries are not specifications.
