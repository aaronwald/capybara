# Prompt

Two kinds (A3 in [[requirements-app]]): a **custom prompt** written for one dispatch, and an **existing prompt** saved in the app's managed prompt library. The library supports add, edit, delete. Prompts attach to a [[task]] when it is dispatched, inside the [[wrapper-prompt]].
